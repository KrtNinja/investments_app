Подключите репозиторий с данными

Приложение не хранит данные само: оно читает и записывает CSV в вашем приватном репозитории на GitHub. Доступ даёт токен, который остаётся только в этом браузере.

Создайте fine-grained токен: GitHub → Settings → Developer settings → Fine-grained tokens. Repository access — только репозиторий с данными, Permissions → Contents: Read and write, срок — не больше года.
